==================================================

1. One EC2 instance automatically provides high availability.
 
2. AWS patches the EC2 guest operating system.
 
3. A managed service means AWS owns every responsibility.
 
4. Vertical scaling automatically equals elasticity.
 
5. Availability automatically equals redundancy.
 
6. Encryption automatically provides authorization.
 
7. Multiple EC2 instances automatically means Multi-AZ.

8. Source code that calls an AWS API directly possesses the IAM permission
   required for that API operation.

9. Long-lived access keys supplied directly to Lambda are the preferred
   workload-identity design.

10. The target role belongs in the caller role's trust policy when the
   caller wants to assume the target role.

11. Corporate access groups displayed through the AWS portal are AWS IAM
   groups.

   AWS temporary session.
